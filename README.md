# Guías de Rift Coach

Guías que la app [Rift Coach](https://github.com/Silentsnake27/rift-coach) descarga sola al abrirse (o con **Guías → Buscar guías nuevas**), sin reinstalar.

- `profiles/`: reglas de cada guía (runas, hechizos, objetos según el rival). Formato `ProfileSpec` de la app.
- `docs/`: guías completas en Markdown (pestaña **Documentos**).
- `index.json`: lista de archivos con su sha256. La app solo descarga lo que cambió y comprueba cada archivo antes de usarlo.

No edites estos archivos a mano: se generan desde el repo de la app con `node scripts/publish-guides.mjs <esta carpeta>`.
